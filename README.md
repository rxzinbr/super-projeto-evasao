# super-projeto-evasao

# Análise de Evasão Acadêmica

## Descrição
Projeto desenvolvido para análise de evasão e desempenho acadêmico utilizando Python.

## Objetivos
- Explorar os dados
- Identificar padrões de evasão
- Realizar análise probabilística
- Gerar visualizações gráficas

## Tecnologias utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Estrutura do projeto

├── dataset.csv
├── projeto.py
├── README.md

## Como executar

1. Instale as bibliotecas:

pip install pandas numpy matplotlib seaborn

2. Execute:

python projeto.py
